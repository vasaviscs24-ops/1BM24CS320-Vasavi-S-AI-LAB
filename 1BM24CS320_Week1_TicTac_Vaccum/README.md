AI Lab – Week 1
Aim

To implement the following Artificial Intelligence programs:

Tic-Tac-Toe Game
Vacuum Cleaner Agent
1. Tic-Tac-Toe Game
Description

Tic-Tac-Toe is a two-player game played on a 3×3 grid. In this program, a human plays against the computer.

Rules
The two players use X and O.
Players take turns marking empty cells.
A player wins by filling an entire row, column, or diagonal with their symbol.
If all cells are filled and nobody wins, the game ends in a draw.
AI Concept Used

Game Tree: Different possible game states are represented as nodes in a tree. Each node represents a board state, and its children represent the possible moves.

Objective

To create a Tic-Tac-Toe game where the human can play against the computer.

2. Vacuum Cleaner Agent
Description

The Vacuum Cleaner Agent is a simple AI-based program that cleans two rooms.

The vacuum cleaner acts as an intelligent agent whose goal is to make both rooms completely clean.

Working
There are two rooms: Room A and Room B.
Each room can be either clean or dirty.
The vacuum cleaner starts in either Room A or Room B.
It checks the room's condition.
If the room is dirty, it performs the cleaning action.
It moves to the other room and cleans it if necessary.
AI Concept Used

Goal-Based Agent: The agent performs actions to achieve a specific goal.

Objective

To reach the final state where both Room A and Room B are clean.

Conclusion

Both programs demonstrate basic concepts of Artificial Intelligence.

Tic-Tac-Toe demonstrates game trees and decision-making.
Vacuum Cleaner Agent demonstrates goal-based agents and state-space search.
